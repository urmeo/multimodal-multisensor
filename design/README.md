# Historical analysis diagram

[Figma board](https://www.figma.com/board/hexcUfwWED4MIu7wjxmWrU/) · [README diagram](../images/pipeline.svg) · [Mermaid source](pipeline.mmd)

The diagram records the workflow before removal of the shared analysis code. This checkout retains the source data and saved results; it cannot rerun those analysis steps.

Recordings and released group tables followed separate paths. The dashed box identifies work blocked by missing acquisition clocks. Most participant summaries lack raw-data mappings. These limits still apply to the saved results.

The SVG contains editable text and vector shapes. The Figma board preserves an earlier version of the design.
